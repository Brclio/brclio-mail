3. [第三方客户端](clients.md)：IMAPS 与 SMTP Submission 参数。
4. [运维、备份与恢复](operations.md)：日志、健康检查、备份、恢复演练和升级。
5. [架构](architecture.md)与[威胁模型](threat-model.md)：数据边界、删除语义、安全能力和责任边界。
6. [限制与路线图](limitations-roadmap.md)：上线前必须了解的缺口。
